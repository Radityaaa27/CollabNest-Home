# Contributing to CollabNest-Home

Thank you for your interest in contributing to the **CollabNest Marketing Website**!

## 🚀 Getting Started

1. **Fork the repository**:
   ```bash
   git clone https://github.com/your-username/CollabNest-Home.git
   cd CollabNest-Home
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Setup environment file**:
   ```bash
   cp .env.example .env
   ```
4. **Run development server**:
   ```bash
   npm run dev
   ```

## 🎨 Guidelines

- Follow existing React component standards and Tailwind CSS practices.
- Ensure accessibility standards (WCAG 2.1 AA) are maintained.
- Test responsive layout across mobile, tablet, and desktop breakpoints.
- Ensure all CTA links utilize `import.meta.env.VITE_APP_URL`.

Thank you for helping make CollabNest visually stunning and performant! 🌟
